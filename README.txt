ADAPTIVE DASHBOARD EVALUATION PROTOTYPE

FILES
- index.html             Dashboard prototype
- style.css              Dashboard styling
- app.js                 Simulated device and interaction logic
- evaluation-guide.html  Researcher task scripts and scoring guide

RUN
1. Open this folder in VS Code.
2. Right-click index.html and choose "Open with Live Server".
3. Open "Researcher setup" in the dashboard.
4. Load a scenario.
5. Click "Enter participant view" before the participant starts.
6. Press Ctrl + Shift + M to restore researcher controls.

IMPORTANT
- No Python, backend, database, or external library is required.
- Every scenario resets to a clean simulated state when loaded.
- All devices can be selected.
- The dashboard guides attention but does not preselect the target device or display the full solution.
- Open evaluation-guide.html separately for the participant scripts and scoring criteria.
